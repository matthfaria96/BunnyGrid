# CLAUDE.md

BunnyGrid: native macOS database client (Swift 6, SwiftUI + AppKit), SwiftPM package. See README.md for layout and docs/ROADMAP.md for phases.

## Build

The active developer dir on this machine is the Command Line Tools, so prefix commands with Xcode:

```sh
export DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer
swift build && swift test
scripts/bundle.sh debug     # build/BunnyGrid.app (compiles Resources/AppIcon.icon with actool)
scripts/preview-icon.sh <dir>   # render the icon in every appearance
scripts/release.sh [--version X.Y.Z] [--notarize]   # dist/: universal app + DMG (docs/DISTRIBUTION.md)
```

Visual check without touching the user's saved connections or driving the mouse:

```sh
BUNNYGRID_DATA_DIR=<scratch dir> build/BunnyGrid.app/Contents/MacOS/BunnyGrid Resources/Samples/demo.sqlite --open-table customers
```
then capture the window with `screencapture -l <windowID>`.

Interactions (drags, menus, typing, wizards) are tested with in-app scenarios: `scripts/ui-test.sh [name…]` runs `scripts/ui-scenarios/*.json` through `--ui-script` (debug-only `App/UIHarness*.swift`: synthetic NSEvents to the app's own windows, never the real pointer). Add a scenario (and `.accessibilityIdentifier`s) for new interactive features and for each interaction bug fixed. Debug-only flags: `--demo-edits`, `--focus-cell`, `--show-objects`.

The UI mirrors Navicat Premium's layout (see the user's reference screenshot): keep new features in the same places (main toolbar, navigator tree, Objects tab, table toolbar/footer, status bar, AI pane). Never copy Navicat's artwork; use SF Symbols.
The AI Assistant talks to Claude (Messages API, default `claude-opus-5-5`, `fallbacks: "default"`), ChatGPT (OpenAI Responses API, default `gpt-6-astra`, `store: false`), or Gemini / Grok / DeepSeek / Mistral / Ollama / LM Studio through OpenAI-compatible Chat Completions (`ChatCompletionsClient`; model picked from the host's `/models`, Ollama and LM Studio need no key), all over raw HTTP (`Sources/BunnyGridCore/AI`). Provider marks are `AIProvider.brand` (Simple Icons, `Resources/Icons/brands/SOURCES.md`). Chat history is stored in Messages-API block shape; `OpenAIClient.input(fromMessages:)` converts it. The platform is picked from the toolbar avatar (`Views/AIAccountView.swift`). Editor Ask AI / Fix with AI live in `Views/AskAIView.swift`; prompts, Markdown blocks and line diff in core (`AIActions`, `MarkdownBlocks`, `LineDiff`). Debug flags: `--account-menu`, `--ai-pane`, `--ai-ask TEXT [--ai-compare]`, `--ask-ai explain|optimize|beautify|fixError|explainError|custom` (with `--query`), `--settings -settingsTab ai`, `-aiProvider chatgpt`. `BUNNYGRID_ANTHROPIC_BASE_URL` / `BUNNYGRID_OPENAI_BASE_URL` / `BUNNYGRID_<PROVIDER>_BASE_URL` point the clients at a proxy or a local mock that speaks the same SSE.

## Rules

- BunnyGrid is free software under the GNU AGPL v3.0 (`LICENSE`), following the user's MacDash. Every open-source package, asset and reference is credited in `THIRD_PARTY_NOTICES.md` and in Settings › About › Open-source licenses, both generated by `scripts/gen-notices.py` (rerun after changing dependencies; add new assets or references to the script). Beekeeper Studio (`../Clones/beekeeper-studio`, GPL-3) is AGPL-compatible: code adapted from it must be credited in the script with its notice.
- Navicat reference is `../Clones/Navicat Premium/SPEC.md` (public bundle metadata only). Don't decompile Navicat.
- `BunnyGridCore` has no UI imports; every engine implements `DatabaseDriver` as an actor. Engine-specific SQL lives in the driver or `SQLDialect`.
- UI state types are `@MainActor @Observable`. Passwords only in the Keychain, never in `connections.json`.
- Distribution: account-specific values (signing identity, notary profile, Sparkle feed/key) only via env or the gitignored `scripts/release.env`. Sparkle is always linked but inert unless Info.plist has `SUFeedURL` + `SUPublicEDKey` (`AppUpdater`). App is Hardened Runtime, not sandboxed (launch agents, ~/.ssh, sockets, SQLite sidecars).
- New core behavior gets Swift Testing tests in `Tests/BunnyGridCoreTests`.
